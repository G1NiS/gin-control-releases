# Security policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in public issues or discussions.
Use [GitHub's private vulnerability reporting](https://github.com/G1NiS/gin-control-releases/security/advisories/new)
and include the affected GIN Control version, impact, reproduction steps, and
any proof of concept that can be shared safely.

Please avoid accessing other people's data, disrupting systems, or publishing
sensitive details while a report is being investigated.

## Supported versions

Only the latest beta release receives security fixes. Upgrade to the newest
version before reporting a vulnerability that may already have been resolved.
