# GIN Control beta feedback guide

Thank you for testing GIN Control. This repository accepts product feedback,
hardware compatibility reports, and release-related questions. The application
source code is maintained privately.

## Choose the right channel

- Use a [bug report](https://github.com/G1NiS/gin-control-releases/issues/new?template=bug_report.yml)
  when an action consistently produces the wrong result.
- Use a [device report](https://github.com/G1NiS/gin-control-releases/issues/new?template=device_not_detected.yml)
  when lighting or fan hardware is missing.
- Use a [feature request](https://github.com/G1NiS/gin-control-releases/issues/new?template=feature_request.yml)
  for a concrete product improvement.
- Use [Discussions](https://github.com/G1NiS/gin-control-releases/discussions)
  for questions, general impressions, and successful hardware test results.

Search existing issues and discussions first. Add new information to an
existing report instead of creating a duplicate.

## Useful details

Please include:

- GIN Control version
- Windows edition, version, and build
- motherboard manufacturer, exact model, and BIOS version if relevant
- exact fan, RGB device, controller, and connection method
- installation path and whether this was a new installation or an update
- numbered steps that reproduce the problem
- expected and actual results
- whether the issue remains after restarting GIN Control or Windows

For fan-control reports, describe what the fans did before, during, and after
the GIN Control service was stopped. Monitor temperatures and return control to
your BIOS or firmware if behavior is unsafe.

## Privacy and safety

Review every attachment before posting it publicly. Remove passwords, account
details, serial numbers, user names, file paths containing personal data, and
other private information. Never disable Windows security features merely to
collect diagnostics.

Security vulnerabilities must be reported privately through
[GitHub Security Advisories](https://github.com/G1NiS/gin-control-releases/security/advisories/new).
